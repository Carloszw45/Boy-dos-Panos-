# Boy dos Panos

Site de moda masculina construído a partir do esboço aprovado, com as mesmas imagens, cores, cards e composição. No celular, cada fileira permanece intacta e permite rolagem lateral, com textos legíveis, cards maiores e áreas de toque de pelo menos 44 px nos controles principais. Categorias, produtos, serviços, inspirações e banners continuam acessíveis na mesma ordem. O layout do computador foi preservado.

[Site público](https://carloszw45.github.io/Boy-dos-Panos-/)

Busca, filtros por categoria, favoritos, detalhes de produtos, inspirações e consulta no WhatsApp são funcionais. Preços, estoque, tamanhos e recebimento de novidades são confirmados pela loja. As imagens dos produtos são ilustrativas do esboço.

## Arquivos

- `index.html`: página e ícones.
- `styles.css`: layout e responsividade.
- `app.js`: interações do catálogo.
- `assets/`: imagens, fonte local e licença.
- `.github/workflows/pages.yml`: publicação automática no GitHub Pages ao atualizar `main`.

Não é necessário instalar dependências ou executar um build local.
